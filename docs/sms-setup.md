# Вход по номеру телефона (SMS.ru)

Как в Мамбе: человек вводит номер, ему приходит код, и только после этого он заполняет анкету. Вход по почте остаётся запасным вариантом (ссылка «Войти по почте» под полем номера).

Код на телефон приходит в СМС: четыре цифры, отправляет сервис SMS.ru. По прайсу SMS.ru (октябрь 2026) это около 8,5 ₽ за СМС; операторы могут потребовать платное имя отправителя (2–3 тыс. ₽ в месяц у каждого).

## Что сделать

1. Зарегистрируйтесь на [sms.ru](https://sms.ru) и пополните баланс (для начала хватит 300–500 ₽).
2. В кабинете откройте раздел «Программистам» и скопируйте **api_id**. Никому его не пересылайте.
3. Зайдите на сервер и запустите:
   ```sh
   lyubov-sms ВАШ_API_ID
   ```
   Команда проверит ключ в SMS.ru (покажет баланс), сохранит его и перезапустит сайт. Лимит СМС в сутки — 300; другой можно указать вторым словом: `lyubov-sms ВАШ_API_ID 500`. Без ключа после команды она спросит его сама.
4. Откройте сайт, нажмите «Войти» и введите свой номер — придёт СМС с четырьмя цифрами.

## Защита баланса

- Новый код на тот же номер — не чаще раза в минуту, с одного IP — не больше 10 в час.
- `SMS_DAILY_LIMIT` (по умолчанию 300) — не больше стольких СМС в сутки на весь сайт. Когда лимит кончается, люди видят просьбу войти по почте, а в журнале сервера появляется запись.
- Коды уходят только на номера стран из `SMS_PREFIXES` (по умолчанию `7` — Россия и Казахстан). Другие страны добавляются через запятую, например `7,375,998`. СМС за границу дороже, и на них чаще всего идёт накрутка.
- Когда на балансе SMS.ru остаётся меньше 100 ₽, сервер пишет предупреждение в журнал (`journalctl -u lyubov`).

## Как это устроено

- Номер хранится в той же колонке, что и почта для входа (`users.email`), в виде `+79991234567`. Админом можно сделать и номер: `ADMIN_EMAILS=почта@ya.ru,+79991234567`.
- Вошедшим по телефону письма-уведомления не отправляются (почты у них нет), push работает как обычно.
- В политике конфиденциальности и согласии SMS.ru указан как получатель номера телефона.
- Код: `server/sms.mjs`, маршруты `POST /api/auth/start` и `/api/auth/verify` в `server/routes/auth.mjs`, тесты — `server/test/sms.test.mjs`.
