# Письма сайта не в спам: Yandex Cloud Postbox + SPF, DKIM, DMARC

## Что сейчас и почему письма попадают в спам

Коды входа уходят через `smtp.yandex.ru` с личного ящика на `@yandex.ru`. Для почтовиков это выглядит как
массовые письма от частного лица «Любовь в цифрах <…@yandex.ru>», а у домена `lyubovvcifrah.ru` нет ни одной
почтовой записи (на 28.11.2026 в DNS нет TXT/SPF, DKIM, DMARC и MX). Добавить SPF/DKIM для домена мало: письма
должны уходить **с адреса на этом домене** — `noreply@lyubovvcifrah.ru` — через сервис, который их подписывает.

Выбран **Yandex Cloud Postbox**: сервис Яндекса для писем сайтов (коды, уведомления).
Первые 2 000 писем в месяц бесплатно, дальше около 80 ₽ за 1 000 писем
([тарифы](https://yandex.cloud/ru/docs/postbox/pricing)). Почтовый ящик покупать не нужно, MX не меняется.
Ответы на письма уходят на почту поддержки (`Reply-To: b1.u@bk.ru`).

## Шаг 1. Аккаунт Yandex Cloud (5 минут, делает владелец)

1. Откройте [console.yandex.cloud](https://console.yandex.cloud/) и войдите своим Яндекс ID.
2. Откройте [billing.yandex.cloud](https://billing.yandex.cloud/) → «Создать аккаунт». Можно на ООО «ЦИФРА И РЕШЕНИЕ»
   (по договору, оплата по счёту) или на себя с картой. Пока писем меньше 2 000 в месяц, денег не спишут.
3. Привяжите облако к платёжному аккаунту, если консоль попросит. Каталог `default` создаётся сам.

## Шаг 2. Адрес в Postbox

1. В консоли наверху в поиске наберите **Cloud Postbox** → **Создать адрес**.
2. Домен: `lyubovvcifrah.ru`. Настройка подписи (DKIM): **Простая**. Нажмите **Создать адрес**.
3. На странице адреса в блоке «Настройка подписи писем (DKIM)» будут **две CNAME-записи** — они нужны в шаге 4.

## Шаг 3. Ключ для сайта

1. В консоли: поиск **Identity and Access Management** → **Сервисные аккаунты** → **Создать сервисный аккаунт**.
   Имя `postbox-user`, роль **postbox.sender**. Каталог тот же, где адрес (обычно `default`).
2. Откройте `postbox-user` → **Создать новый ключ** → **Создать API-ключ**, область действия **yc.postbox.send**.
3. Окно покажет **идентификатор** и **секретный ключ**. Не закрывайте его до шага 5 — секрет показывается один раз.
   В чат ключ не присылайте.

## Шаг 4. Записи в DNS на reg.ru

[reg.ru → Домены](https://www.reg.ru/user/account/#/domains) → `lyubovvcifrah.ru` → **DNS-серверы и управление
зоной** → **Добавить запись**. В поле «Субдомен» reg.ru сам дописывает `.lyubovvcifrah.ru`, поэтому домен в имя не пишите.

| Тип | Субдомен | Значение |
|---|---|---|
| CNAME | первое имя из Postbox **без** `.lyubovvcifrah.ru` (вида `…._domainkey`) | первое значение из Postbox |
| CNAME | второе имя из Postbox без домена | второе значение из Postbox |
| TXT | `@` | `v=spf1 include:spf.postbox.yandexcloud.net ~all` |
| TXT | `_dmarc` | `v=DMARC1; p=none; adkim=r; aspf=r` |

- **DKIM** (две CNAME) — подпись писем, главное против спама. Ключи хранит и меняет Postbox.
- **SPF** — список серверов, которым можно слать письма от домена. На домене должна быть только одна запись `v=spf1`.
- **DMARC** — что делать с поддельными письмами. `p=none` — пока только наблюдение. Через неделю, когда письма
  стабильно доходят, поменяйте на `v=DMARC1; p=quarantine; adkim=r; aspf=r` — поддельные письма от имени сайта
  будут уходить в спам, а настоящие получат больше доверия.

Записи применяются от 15 минут до нескольких часов. В Postbox статус адреса сменится на **Success**
(если за сутки не сменился — кнопка «Запустить проверку»).

## Шаг 5. Включить на сервере

В PowerShell:

```powershell
ssh -t root@109.196.98.179 lyubov-mail
```

Выберите `1`, адрес отправителя — Enter (`noreply@lyubovvcifrah.ru`), вставьте идентификатор и секрет ключа
(правая кнопка мыши), почта для ответов — Enter. Сайт перезапустится сам.

Если команда спрашивает старое «Адрес почты на Яндексе», значит на сервере старая версия команды. Тогда так:

```powershell
ssh -t root@109.196.98.179 bash /opt/lyubov/deploy/lyubov-mail.sh
```

## Проверка

1. Войдите на сайт по почте на Gmail и на Mail.ru — код должен прийти во «Входящие».
2. В письме: Gmail → «⋮» → «Показать оригинал»: `SPF: PASS`, `DKIM: PASS`, `DMARC: PASS`.
3. Ещё точнее: [mail-tester.com](https://www.mail-tester.com/) — войти на сайт с показанным там адресом и нажать «Проверить».
4. Если письма нет: `ssh root@109.196.98.179 "journalctl -u lyubov -n 30 | grep smtp"`.

## Что ещё помогает доставке

- [Постмастер Mail.ru](https://postmaster.mail.ru/) и [Постмастер Яндекса](https://postmaster.yandex.ru/) —
  добавить домен, там видно, сколько писем ушло в спам.
- Не слать письма на несуществующие адреса (Postbox сам ведёт стоп-лист).
