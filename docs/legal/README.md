# Юридическая часть и Робокасса: что сделать и в каком порядке

> Это не юридическая консультация. Перед запуском желательно один раз показать документы юристу по 152-ФЗ (обычно это 1–2 часа консультации).

## Что уже сделано на сайте

- Политика обработки ПД, отдельное согласие на обработку и отдельное согласие на распространение (показ анкеты), пользовательское соглашение, оферта — на русском и английском, отметка 18+.
- При регистрации три отдельные незаполненные галочки; сервер сохраняет время и версию каждого согласия.
- Метрика включается только после «Принять» в плашке cookie, Вебвизор выключен.
- Шрифты на своём сервере (не уходят данные в Google), push выключен по умолчанию (нет трансграничной передачи).
- Пользователь сам скачивает свои данные и удаляет анкету; удаление пишется в журнал уничтожения; селфи удаляется не позже 30 дней.
- Оплата: заказы в админке, возвраты, автоматическая сверка с Т-Кассой.
